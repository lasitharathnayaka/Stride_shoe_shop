# Stride — Shoe Store

Full-stack shoe store web application (currently scaffolding the frontend; Express backend will be added under `server/`).

## Tech Stack
- **Frontend (`client/`):** React, TypeScript, Vite, Tailwind CSS, React Router
- **Backend (`server/` — planned):** Node.js, Express, TypeScript

## Getting Started

```bash
cd client
npm install
npm run dev
```
